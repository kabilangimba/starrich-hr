{#- Boot splash: shown by the Desk while its bundle loads, and by website pages (including /login) while theirs does. Shadows frappe/templates/includes/splash_screen.html - ai_hr resolves ahead of frappe in the template search order - so no core file is edited. The stock splash is a bare logo on white, which reads as a stalled page rather than a loading one; this adds a progress bar under it. The CSS is inline, not in a bundle, for two reasons: * This template renders on both Desk and website pages, and no single hook covers both - `app_include_css` misses /login, `web_include_css` misses the Desk. Carrying its own styles makes the splash work wherever it appears. * Inline styles are parsed with the markup, so the bar is painted on the first frame - a linked stylesheet is a second round trip during the exact window this element exists to cover. The bar is pure CSS, not a lucide icon, because `include_icons()` does not inline the sprite: it emits a script that fetches it at runtime. The splash is on screen while that fetch is still in flight, so a would point at a symbol that does not exist yet and draw nothing. -#}
